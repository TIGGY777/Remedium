Remedium — MVP 1.0

В архиве ровно 5 файлов:
index.html
manifest.json
sw.js
icon-180.png
README.txt

Включено:
— онбординг;
— главная Remedium в согласованном стиле;
— единая лента здоровья и поиск;
— зубная карта 32 зубов;
— активный план лечения с прогрессом и этапами;
— клиники с обычными фотографиями по внешним URL, галереями, рейтингом, отзывами и полным прайсом;
— врачи без фотографий;
— запись: клиника → направление → врач → услуга → цена → дата → время → подтверждение;
— перенос времени, смена врача/клиники и отмена записи;
— планы лечения, заключения, карточка КЛКТ, фотопротокол и электронные чеки;
— расходы по дню/неделе/месяцу/году/всему времени, со сменой списка услуг;
— локальное сохранение изменений через localStorage;
— демо-кабинет клиники: завершение визита автоматически добавляет пациенту визит, заключение, чек и расход;
— PWA cache remedium-mvp-100.

Для GitHub:
1. Удалите старые JPG из прошлой сборки — MVP 1.0 их не использует.
2. Замените в корне репозитория эти 5 файлов.
3. Commit changes.
4. После публикации откройте сайт в Safari и обновите.
5. Для чистой установки удалите старую иконку Remedium с экрана «Домой» и добавьте сайт заново.

Важно: фотографии клиник/тестового фотопротокола загружаются по внешним URL. Реальные медицинские данные в публичный GitHub не загружать. Для production потребуется backend, авторизация, защищённое хранилище и соблюдение требований к персональным/медицинским данным.

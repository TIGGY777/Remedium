Remedium V0.4.1

Добавлено:
• локальные тестовые фото трёх клиник и врачей;
• открываемые содержательные планы лечения;
• открываемый КЛКТ;
• открываемый фотопротокол с отдельными изображениями;
• заключение врача;
• детальные чеки;
• управление будущей записью: перенос времени, смена врача, смена клиники, отмена;
• расходы по периодам с динамической сменой списка услуг, клиники, врача, даты и суммы.

Важно: изображения и документы являются синтетическими тестовыми материалами прототипа, а не настоящими медицинскими документами реальных пациентов.

Для обновления загрузите в корень GitHub ВСЁ содержимое архива, включая JPG-файлы, с заменой существующих файлов.

Remedium V0.4
Визуальная концепция возвращена к расширенной версии: чёрная карточка медицинского профиля, рекомендация, плитки быстрых действий, последнее посещение и нижняя навигация.

Добавлено/сохранено:
- Клиники сразу списком.
- Внутри клиники направления фильтруют только врачей этой клиники.
- Карточки врачей и отзывы.
- Рабочая демо-запись: клиника → направление → врач → услуга/цена → слот → подтверждение.
- История с клиникой, врачом, стоимостью и документами визита.
- Кликабельные планы лечения, КЛКТ, фотопротоколы, заключения и чеки.
- Профиль и расходы по периодам.
- PWA cache version remedium-v040.

Для обновления GitHub Pages замените ВСЕ 5 файлов и сделайте Commit changes.
Все медицинские данные в прототипе демонстрационные.

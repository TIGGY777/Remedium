Remedium — MVP 1.1

Что изменено по сравнению с MVP 1.0:
• экран «История» переработан в более дорогой визуальный формат, ближе к одобренному макету;
• зубная карта переделана в анатомическую схему верхней и нижней челюсти;
• карточка выбранного зуба теперь открывается прямо под картой;
• фотографии клиник заменены на более презентабельные и премиальные по восприятию;
• структура архива по-прежнему состоит только из 5 файлов;
• новый cache version: remedium-mvp-110.

Файлы в архиве:
1. index.html
2. manifest.json
3. sw.js
4. icon-180.png
5. README.txt

Установка:
1. Распакуйте архив.
2. В корне GitHub-репозитория Remedium замените текущие 5 основных файлов этими пятью.
3. Commit changes.
4. Дождитесь публикации GitHub Pages.
5. Откройте сайт в Safari и обновите страницу.
6. Если на iPhone установлена старая иконка приложения, удалите её и добавьте сайт заново.

Важно:
• изображения клиник подгружаются по внешним URL, поэтому дополнительные JPG в GitHub не нужны;
• используются только демонстрационные данные.
